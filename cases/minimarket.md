# Minimarket Demo · gestión de tienda

**Problema:** reunir inventario, ventas, caja, fiados y revisión de facturas en un flujo consultable.

**Código público:** prototipo Flask con permisos de administrador y vendedor y parser de DTE. El catálogo se generó para la demostración, con nombres y cifras inventados.

**Alcance:** historial nuevo, sin bases de datos, documentos tributarios ni registros del negocio. El repositorio original se conserva privado y esta edición es independiente.

**Límites:** prototipo para ejecución local; requiere revisión de permisos, protección de formularios y aritmética monetaria antes de un despliegue productivo. Las funcionalidades se presentan como trabajo construido, no como prueba de adopción o impacto medido.
