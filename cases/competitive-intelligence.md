# Inteligencia competitiva · evidencia a acciones

**Problema:** un reporte periódico era difícil de consultar, repetía información y no facilitaba comprobar si las acciones propuestas se ejecutaban.

**Trabajo:** definir una herramienta consultable para revisar hallazgos, noticias, briefs y acciones vinculadas a evidencia; iterar la experiencia para equipos de negocio. El proyecto de origen incluyó integración de datos, Apps Script, clasificación asistida y validación en entornos DEV y PROD.

**Ejemplo público:** deduplicación de fuentes, conservación de evidencia y acciones enlazadas a hallazgos. Se reconstruyó como código independiente: no incluye el clasificador, sus prompts, fuentes, arquitectura privada ni datos del sistema original.

**Resultado técnico del origen:** una herramienta desplegada con seguimiento de acciones y evolución de funcionalidades. No se publica una cifra de impacto comercial porque no se ha establecido una medición para este caso.

**Aporte:** definición del problema, prioridades, comportamiento de la herramienta y revisión de resultados, con desarrollo asistido por IA.
